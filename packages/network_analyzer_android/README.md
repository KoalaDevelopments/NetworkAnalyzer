# network_analyzer_android

The Android implementation of [`network_analyzer`](../network_analyzer),
written in Kotlin.

This package is endorsed: host applications depend on `network_analyzer`
only, and the Flutter tool wires this implementation in automatically.

## Platform channel

Dart↔Kotlin messaging is generated by pigeon from
`pigeons/messages.dart`:

```shell
dart run pigeon --input pigeons/messages.dart
```

Outputs (`lib/src/messages.g.dart`, `Messages.g.kt`) are committed after
generation. Never hand-write channel code.
