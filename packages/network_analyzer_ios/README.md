# network_analyzer_ios

The iOS implementation of [`network_analyzer`](../network_analyzer),
written in Swift (Swift Package Manager layout, with a CocoaPods podspec
for compatibility).

This package is endorsed: host applications depend on `network_analyzer`
only, and the Flutter tool wires this implementation in automatically.

## Platform channel

Dart↔Swift messaging is generated by pigeon from
`pigeons/messages.dart`:

```shell
dart run pigeon --input pigeons/messages.dart
```

Outputs (`lib/src/messages.g.dart`, `Messages.g.swift`) are committed
after generation. Never hand-write channel code.
